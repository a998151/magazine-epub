# 配置表字段说明（build_epub.py）

此构建器面向工作目录根部包含 `content.opf`、`toc.ncx` 和分章 HTML 的源书。若原书的 OPF 在子目录，或多章共用一个 XHTML，按包内实际结构适配。章节名与文件从 OPF 的 spine 和导航核对。

## 顶层字段

| 字段 | 必填 | 说明 |
| --- | --- | --- |
| `source` | ✅ | 源 `.epub`（zip）或已解压目录。zip 会自动解压到 `workdir` |
| `workdir` | | 选新的构建工作目录。脚本会清空同名目录后重建 |
| `output` | ✅ | 输出的 `.epub` 路径 |
| `css` / `page_css` | | 自定义样式表路径；缺省用本 skill 的 `references/magazine.css` 与 `references/page.css` |
| `book` | | 开篇页内容，见下 |
| `toc_entries` | | 开篇页底部的目录条，`[{"no":"01","title":"秋"}]` |
| `drop_pages` | | 要删除的源文件（盗版广告页、重复目录页），会同步从 `content.opf` 的 manifest/spine 移除 |
| `drop_ids` | | 额外要移除的 manifest id（源文件删不掉但不想出现在书里的资源） |
| `front_matter` | | 前置页文件名（版权页 / 目录页 / 注释页）。会加 `front-matter` class，用来关掉首字下沉 |
| `ad_patterns` | | 推广关键词列表。命中的 `<p>` 整段删除 |
| `notes_page` / `notes_title` | | 给指定的前置页补标题：`notes_page` 是文件名（如 `index_split_011.html`），`notes_title` 是标题文字 |
| `chapters` | | 章节配置表，见下 |
| `images` | | `{"名称": "/绝对路径.jpg"}`，名称即包内 `images/名称.jpg` 的文件名 |
| `image_max_width` | | 压图后的最大宽度，默认 1400 |
| `image_quality` | | JPEG 质量，默认 80 |
| `opener` | | `true` 时生成带图刊头页。需要 `book.image` 在 `images` 中，且原 spine 有 `titlepage` 项可供插入 |
| `toc_page` / `toc_label` | | 在 NCX 里插入的目录页导航项 |

## `book`（开篇页）

| 字段 | 说明 |
| --- | --- |
| `title` | 书名。命中 `title_accent` 的部分会被 `<em>` 包住 → 朱砂高亮 |
| `title_accent` | 要高亮的片段，如"血色馈赠" |
| `title_en` | 英文题名 |
| `subtitle_en` | 刊头上方那行小号斜体英文（kicker） |
| `deck` | 导语。用朱砂竖线 + 楷体 |
| `byline` | 数组，如 `["某某 著 · 某国", "某某 译"]` |
| `masthead_left` / `masthead_right` | 刊头左右两栏文字 |
| `image` / `image_alt` / `caption_cn` / `caption_en` | 开篇页主图 |

## `chapters[]`

| 字段 | 必填 | 说明 |
| --- | --- | --- |
| `file` | ✅ | 按原 spine 确认的正文文件路径，如 `index_split_003.html` |
| `no` | | 序号，显示为朱砂大字 |
| `cn` / `en` | | 中文章名 / 英文名 |
| `image` | | 插图名（对应 `images` 里的键） |
| `alt` | | 图片替代文本（无障碍，必填） |
| `caption_cn` / `caption_en` | | 图注，中英各一句 |
| `pull_quote` | | **可选，默认不填**。抽言句，必须逐字等于正文中的某一句。仅在用户明确要求做抽言时启用 |
| `pull_source` | | 抽言出处，如 `《秋》`，仅在启用抽言时填 |

# 内容策划方法

## 插画选项

用户选择生成、尚未选定画风时，从这里提供选项。

| 画风 | 视觉特征 |
| --- | --- |
| 经典黑白木刻版画（默认） | 粗粝刀痕、强明暗对比和大块留白 |
| 黑白木刻 · 细线版 | 细刻线和交叉排线刻画更多层次 |
| 低饱和水彩 | 柔和色块、淡彩晕染和纸纹 |
| 黑白水墨叙事（国风志怪） | 墨色浓淡与雾气铺陈氛围，关键人物和物件用细线描清 |
| 维多利亚小说蚀刻风 | 黑白细线与层叠排线塑造明暗，强调人物姿态和场景细节 |
| 石墨铅笔素描 | 轻擦灰阶、细颗粒与手稿质感 |
| 黑白钢笔线描 | 清晰轮廓、轻重不同的笔线与留白 |
| 彩色木版套印 | 少量套色组成平面色块，保留木刻印痕 |
| 水粉插画 | 哑光色块层叠，显露厚实笔触 |

## 插画意象怎么选

结合本章首段和反复出现的具体物象选场景，图注避免泄露后续情节。例如，反复出现的矿井与教堂钟声，可以画成矿区、井架和远处的钟楼。

## 生成 prompt 的写法

一套图共用同一段风格描述词：

> 黑白木刻版画风格插画：<场景>，粗粝刀刻线条，强烈明暗对比，大面积留白，凸版印刷颗粒肌理。<构图>。无文字，无边框。

- 指定画幅和主体位置，排除文字与边框。正文插图可用 3:2，刊头和画入纸面章首可用 16:9。画入纸面的关键主体放在中上部，留出横裁和湿边空间。

### 跨图角色一致性

1. 出图前，从原文提取反复出场的角色的年龄感、脸型、发型、体态和辨识特征，如缺眉、眼镜或惯用配饰。原文没交代的特征可为配图确定一种合理设计，并在全书沿用。黑白插画优先选靠轮廓和明暗也能辨认的特征。
2. 在每张有该角色的图中原样复用这段外形描述。工具支持参考图时，优先采用符合原文且形象清楚的已有插图，否则先生成一张可作参考的图。后续场景复用同一张角色参考图，按本章调整姿势、表情、衣着和场景。故事明确发生了年龄、发型或服装变化时，写出对应阶段的变化，保留仍适用的辨识特征。
3. 将同一角色的成图并排对照原文设定和参考图，核对脸型、发型、年龄感和标志特征，并检查同框角色是否串脸。发现走样时，沿用原设定与参考图，仅修正或重生成有问题的图，复核后再写入构建配置。

### 黑白水墨叙事（国风志怪）

> 单色黑白水墨叙事插画，<本章事件、人物与关键物件>。淡墨晕染云雾和远景，浓墨勾画近景的岩石、草木与衣褶，人物和关键物件用细线描保持清楚。前中远景分明，灰阶丰富，运用纸面留白；整体静谧、悬疑。横向构图，无文字、题款、印章和边框。

### 维多利亚小说蚀刻风

> 19 世纪英国小说的黑白蚀刻风插画，<本章人物、动作与场景>。细密而有弹性的墨线，逐层改变交叉排线的方向和密度，刻画人物表情、衣褶与环境中和情节有关的细节。像舞台场面一样组织动作与视线，局部保留明亮纸白，画面边缘让排线逐渐疏开，自然收进纸面。服装和器物遵循原文时代背景。无文字、签名、边框或水印。

### 石墨铅笔素描

> 石墨铅笔书籍插画，<本章场景>。用疏密有别的短笔触和轻擦层次塑造形体，暗部保留铅笔颗粒，亮部透出纸白。灰阶柔和，重点轮廓清楚。无文字，无边框。

### 黑白钢笔线描

> 黑白钢笔线描书籍插画，<本章场景>。用轻重有别的轮廓线和少量细节线区分前后层次，阴影从简，保留大块白纸和清晰的物体边界。无大面积交叉排线或灰度晕染，无文字，无边框。

### 彩色木版套印

> 彩色木版套印书籍插画，<本章场景>。用三至四块固定套色组织构图，可选靛蓝、赭黄、朱红和纸白。保留清楚的刀刻痕、少量油墨不匀和轻微套准偏差，色块平涂。整组复用同一套色。无文字，无边框。

### 水粉插画

> 不透明水粉书籍插画，<本章场景>。用哑光颜料层叠出厚实、边缘略带刷痕的色块，用色块和笔触区分前后景。用一致的低饱和底色衬出叙事焦点。无文字，无边框。

## 图注的写法

- 中文一句点出场景与气氛，英文与中文语义对应。

```html
<figcaption><span class="cn">港口不大，海岸的弧线也柔和。</span><span class="en">The harbour at first light.</span></figcaption>
```
