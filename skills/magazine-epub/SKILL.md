# Magazine EPUB

保留原文、段落顺序、目录和脚注。确认属于广告或重复导航的内容才清理。使用新路径输出，保留原始 EPUB。

## 1. 确认版式和配图

- 确认目标阅读器与所选版式。Kindle 使用单栏。需要用户选版时，从同一个源 EPUB 打包并渲染同一实际页面。已选定的版式直接沿用。[版式与预览](references/layouts.md)
- 改包前确认用户是否需要生成插画，等待答复。**不生成**时保留原书图及图注，继续排版、打包和校验。**生成**时确认配图范围和画风，待选定后再开始。用户已确认的选择直接沿用。[插画选项](references/recipes.md#插画选项)
- 版式与画风独立选择。带新图的刊头页按需制作。

## 2. 体检与构建

```bash
python3 scripts/inspect_epub.py book.epub
python3 scripts/build_epub.py --config config.json
```

- 先用 `file` 区分压缩包与解包目录。按 OPF spine 和导航确认章节文件与阅读顺序。体检脚本若未列出章节，从 `META-INF/container.xml` 定位 OPF，按 `idref` 回查 manifest。疑似重复目录和推广命中先核对页面内容，保留译者注、有效书内导航和书单等原书内容。
- 原书结构适配构建脚本时，用新的工作目录运行。OPF 路径、正文命名或标题结构不兼容时，按实际 XML 节点适配，保留原阅读顺序与锚点。无新增插画时省略图片与新增图注字段，关闭新增带图刊头页。[构建配置与适用结构](references/recipes.md)
- 配图先复用适合的原图。用可用的图像生成工具补图，场景取自各章原文。重复出场的角色复用外形描述和参考图，入包前并排核对。新增章首图配简短的替代文字和中英图注。[提示词、人物与图注](references/recipes.md#内容策划方法)
- 构建后再应用所选预设。「画入纸面」用真实 XHTML 排列章首图、章题、花饰和正文，并将图注放到首个章页末尾。[应用预设](references/layouts.md#应用已选预设)

## 3. Kindle 轻量化

排版完成后、预览之前，用 `scripts/kindle_compact.py` 另存。画入纸面默认生成**纯白底湿边 PNG**。原不规则轮廓和窄过渡保留，清除外围淡灰残影，以纯白衔接 Kindle 页面。需要其他阅读器的透明版时，从同一份含原始湿边 PNG 的 EPUB 另出 `--wet-edge alpha`。图片预算、旧版迁移和书内外边距选项见 [Kindle 轻量化](references/layouts.md#kindle-轻量化)。

## 4. 验收与交付

- **结构与内容**。核对 `mimetype` 是首条且不压缩，manifest、spine、目录和脚注跳转有效。逐字比对正文并核对段落顺序。只比对脚本覆盖到的段落时，补查未覆盖的正文、序跋与注释。
- **最终包预览**。从实际交付的 EPUB 渲染卷首及至少一个正常章节。画入纸面检查窄屏章首宽度、湿边、章题花饰、图注与目录落点。无新增插画时检查原图仍可显示且没有空图引用。有首字下沉时核对它作用于正文。[预览命令](references/layouts.md#给用户选版)
- **Kindle 输出**。验证纯白版的湿边外围为 RGB `255,255,255`，透明版的对应区域为 alpha `0`。如果启用了书内零外边距，有编号小节时比较第 1、2 小节。汇报轻量化前后体积和单张最大体积，并注明 Kindle 实机验证状态。[阅读器兼容性](references/compatibility.md#kindle)
- 交付成品 EPUB 和实际包渲染的预览。保留可重跑的构建配置、样式、源路径和构建命令。ZIP 外包装按需提供。
